## 命令表

### 感情管理

| 命令格式 | 说明 |
| :--- | :--- |
| `/注册感情 <角色名> <情感名> <参考音频路径> <音频对应文本> [语言]` | 注册一个新的情感，用于语音合成。<br>`[语言]`为可选参数(默认jp)，可选: `jp`,`zh`,`en`。<br>**注意**：`<参考音频路径>` **必须**是您上传到模型仓库 `reference_audio/` 文件夹下的**相对路径**，例如：`reference_audio/Kisaki_happy.wav`。 |
| `/删除感情 <角色名> <情感名>` | 删除一个已注册的情感。 |
| `/查看感情 [角色名]` | 列出所有已注册的角色及其拥有的情感；带角色名则只看这一个。末尾附「共 N 个角色 / M 条感情」统计。 |
| `/感情导出 [角色名]` (`/导出感情`) | 把感情库导出成感情包 JSON：给出摘要、在服务端存一份快照，QQ 平台还会直接发 `.json` 文件；省略角色名则导出全部。 |
| `/感情导入 [模式] [试运行]` (`/导入感情`) | 导入感情包。JSON 可以贴在同一条消息里、引用一条含 JSON 的消息，或上传 `.json` 附件；裹在 Markdown 代码块里也能识别。 |
| `/感情包` (`/感情包列表`) | 列出服务端保存的感情包快照（角色数 / 感情数 / 体积 / 时间，按时间倒序）。 |
| `/感情包保存 [文件名]` | 把当前感情库另存为一份服务端快照；同名文件不会被覆盖。 |
| `/感情包恢复 <文件名> [模式] [试运行]` | 从快照恢复感情库，可先「试运行」看清会改什么再真正写入。 |

### 核心功能

| 命令 (别名) | 说明 |
| :--- | :--- |
| **自动情感识别模式 (推荐)** | |
| `/tts-w` (`/开启自动情感识别`) | 为**当前对话**开启“自动情感识别”语音合成模式。 |
| `/sw-w <角色名>` | 在“自动情感识别”模式下，为**当前对话**切换使用的角色。 |
| `/tts-w-q` (`/关闭自动情感识别`) | 单独关闭“自动情感识别”模式。 |
| **固定情感模式** | |
| `/tts-llm` (`/开启语音合成`) | 为**当前对话**开启“固定情感”语音合成模式。 |
| `/sw <角色名> <情感名>` | 在“固定情感”模式下，为**当前对话**临时切换使用的情感。 |
| **群组指令** | |
| `/ttg` (`/开启群语音`) | 开启**当前群组**的语音合成 (对所有人生效)。<br>若开启了LLM情感注入，则为自动情感模式；否则为固定情感模式。 |
| `/ttg-q` (`/关闭群语音`) | 关闭**当前群组**的群级自动配音，单独开启的会话仍有效。开启状态持久化时重启保留；要彻底禁用请加入配置群黑名单。 |
| **通用指令** | |
| `/tts-q` (`/关闭语音合成`) | 清除**当前会话**的普通／自动情感开关，仍可继承群级配音；关闭群级配音用 `/ttg-q`。 |
| `/合成 <角色名> <情感名> <文本>` | 手动合成语音。若文本含空格，建议用英文双引号 `"` 括起来。 |
| `/tts-again` (`/重发语音`) | 重发本会话最近一条合成成功的语音，不重新消耗 TTS 算力。临时音频被定时清理后会提示重新合成。 |
| **诊断指令** | |
| `/tts-status` (`/语音状态`) | 查看本会话/本群开关、当前音色是否可用、触发与输出模式、合成统计、排队数量，并并发探测所有 TTS 服务器。排查「怎么不发语音了」的第一站。 |
| `/tts-help` (`/语音帮助`) | 列出插件全部指令与别名。 |

### 语音收藏

这些指令都能靠**引用**一条语音消息来指定目标（长按语音 → 回复）。`/语音收藏` 和 `/语音转文件` 在不引用时会自动取本会话最近一条 bot 语音；其余指令按序号或名字定位，序号就是 `/收藏列表` 里显示的那个。

| 命令 (别名) | 说明 |
| :--- | :--- |
| `/语音收藏 [名字]` (`/收藏语音`、`/tts-fav`) | 把引用的那条语音存进音库。带名字方便以后 `/发收藏 早安` 这样叫，重名自动加 `-2`。同一段音频重复收藏会按 sha256 去重，只补名字不占地方。 |
| `/收藏列表 [关键词\|页码]` (`/语音收藏列表`、`/tts-favs`) | 列出收藏，一页 8 条，置顶的排最前。带关键词按名字 / 正文 / 角色 / 感情筛。末尾附「共 N/上限 条 · 总体积 · 总时长」。 |
| `/发收藏 <序号\|名字>` (`/播放收藏`、`/tts-fav-send`) | 把收藏的语音原样发回来，**不重新合成**，不消耗 TTS 算力。会累加播放次数。 |
| `/收藏文件 <序号\|名字>` (`/收藏转文件`、`/tts-fav-file`) | 把收藏的语音当**文件**发出来（附件名带序号和名字），可以直接存到手机或电脑。 |
| `/语音转文件` (`/语音存文件`、`/tts-to-file`) | 不入库，直接把一条语音转成文件发出来。**不受收藏总开关限制**，也不看群黑名单。 |
| `/收藏改名 <序号\|名字> <新名字>` (`/tts-fav-rename`) | 改名。新名字留空则清掉名字（列表里回落成 `#` 加音频 ID 前 6 位）。 |
| `/收藏备注 <序号\|名字> [备注]` (`/tts-fav-note`) | 改这条在列表里显示的那段正文。省略备注即清空。 |
| `/收藏置顶 <序号\|名字>` (`/tts-fav-pin`) | 置顶 / 取消置顶（再发一次就取消）。置顶的排最前，且**永不被容量淘汰**。 |
| `/收藏导出 [序号,序号…]` (`/导出收藏`、`/tts-fav-export`) | 把收藏打包成 `.zip` 发出来。不带参数导出全部，也可以 `/收藏导出 1,3,5` 只导指定几条。 |
| `/收藏导入 [merge\|overwrite\|replace]` (`/导入收藏`、`/tts-fav-import`) | 导入收藏包 zip：把文件传在同一条消息里，或引用一条带附件的消息。模式语义和感情包一致，默认 `merge`。 |
| `/删收藏 <序号\|名字>` (`/删除收藏`、`/tts-fav-del`) | 删掉一条，音频文件一起清掉。 |
| `/收藏清空 [含置顶] [确认]` (`/清空收藏`、`/tts-fav-clear`) | 清空音库。不带 `确认` 只给预览（会删几条、留几条），默认保留置顶；加 `含置顶` 才连置顶一起删。 |

## LLM 主动语音工具

当用户明确提出“说句话听听”“发段语音”“念给我听”这类要求时，LLM 可以主动调用 `genie_tts_speak` 工具，直接向当前会话发送一条语音。

- 这个工具不会替代平时的三种自动触发模式。
- 它更适合一次性的“来段语音试听”场景。
- 工具调用的发送方式由 **LLM工具输出模式** 单独控制，默认是纯语音。
- 插件会把当前角色的可用情感注入给 LLM，引导它调用工具时填写 `emotion_name`，减少总是落回默认情感的情况。
- 工具文本里若误带 `[emotion=xxx]` 或 `$...$`，插件也会尝试解析并清理后再送入 TTS。
- 合成前会自动补齐句末标点，降低后端分句时尾音被截断的概率。
- 如果当前 **外语TTS准备方式** 为 `llm_injection`，主 LLM 会被提示先把内容翻成目标语言，再调用工具。
- 如果当前 **外语TTS准备方式** 为 `provider_translation`，工具可以直接传原文，插件会负责翻译。
- 工具发送过语音后，插件会自动跳过本轮普通自动 TTS，避免同一轮回复重复发两次声音。
