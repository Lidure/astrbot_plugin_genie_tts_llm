# 🎧 语音收藏：把 bot 发过的好语音留下来

[← 文档索引](README.md) · [项目主页](../README.md)

有时候 bot 随口念的那句特别对味，重新合成一次却怎么都不是那个感觉 —— 采样本身带随机性，同样的文本和感情也抽不回同一条。收藏功能就是为这个准备的：**把那一份音频原样留住**。

**怎么用**

1. 长按 bot 发的那条语音 → 回复 → 发 `/语音收藏 早安`
2. `/收藏列表` 看看存了什么
3. 想再听就 `/发收藏 早安`，想存到本地就 `/收藏文件 早安`

不引用也行：`/语音收藏` 会取本会话最近一条 bot 语音（插件在内存里留最近 16 条）。

**关于音质**

- 收藏走的是逐字节复制，**不解码、不重编码、不改采样率**，存进去的和 bot 当时发出来的是同一份字节。
- 只有一种情况会有损：引用的语音已经不在插件的临时目录里（重启过、清理过，或者那条本来就不是插件发的），这时只能从协议端反取，而 QQ 侧存的通常已经转成过 amr/silk。这类条目在列表和工作台里带一个 `有损` 角标，`/语音转文件` 也会明确写出来。

**存在哪 / 会不会被清掉**

`data/plugin_data/astrbot_plugin_genie_tts_llm/voice_vault/`，`index.json` 记元信息、`audio/` 放音频。这个目录**不在**临时音频的 30 分钟清理范围内 —— 除了你自己删和容量淘汰，没有别的东西会碰它。索引文件万一写坏了也不致命：下次加载会从 `audio/` 目录把音频重新挂回来（元信息会丢，音频不丢）。

**收藏包**

`/收藏导出` 打出来的 zip 结构是 `index.json` + `audio/<id>.wav`，拷到另一台机器上 `/收藏导入` 就行。三种合并模式和感情包一致（`merge` / `overwrite` / `replace`）。工作台的「★ 收藏」页里也能点着做，还能顺手挑几条单独导出。
